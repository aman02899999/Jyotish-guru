How this login works

Your passphrase is checked against a PBKDF2-SHA256 hash (210,000 iterations) — no plaintext password exists in this repository.

Because this is a static site with no server, this gate is a deterrent, not a cryptographic boundary. The real protection is the GitHub token: publishing changes requires a token that GitHub validates server-side. Without one, anyone reaching this panel can only alter what their own browser shows — never the live site for other visitors.
